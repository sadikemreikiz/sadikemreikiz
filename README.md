**[Master's thesis, rebuilt: financial document fraud detection](https://github.com/sadikemreikiz/financial-document-fraud-detection)** — My Master's thesis, rebuilt from scratch. When I audited the original implementation, I found that its headline results were not valid: among other issues, test documents had leaked into training. The new version is evaluated under a protocol fixed before any model was trained, with a locked test set. So far it has uncovered a format shortcut in the dataset that alone beats the best published result, reproduced the published baseline, and combines OCR-based accounting checks with pixel-forensics models in PyTorch. Work in progress.
